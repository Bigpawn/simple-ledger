验证边界：

- 周期账单目前是月周期，到期后在 App 内生成待确认项，没有系统推送提醒。
- 设备内快照在 Web 使用浏览器本地存储，在原生端写入 App 文档目录；卸载 App 后仍会丢失，跨设备恢复必须导出 JSON。
- 浏览器验收未实际执行快照恢复或外部备份恢复，因为两者会覆盖当前数据；恢复写入路径已完成类型检查和源码核验，仍需在隔离数据上做原生真机确认。
